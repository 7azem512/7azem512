About Me

I'm a Computer Science graduate from Menoufia University focused on backend engineering with Java and Spring Boot.

I enjoy building systems where the interesting work starts after the endpoint returns 200 OK: authentication, authorization, concurrency, caching, messaging, real-time communication, resilience, data consistency, service-to-service communication, and observability.

I care about understanding how the whole system behaves, especially when something fails.
